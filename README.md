# kalodata 浏览器辅助脚本

这是一组用在 Kalodata 上的浏览器辅助脚本，核心用途是**跨境电商市场调研中的数据整理提效**。调研时需在商品榜和商品详情页之间反复翻查，把商品名、规格、卖点、评价逐条抄录成表格，既慢又重复；两个脚本把这些操作收在同一页面完成。

仓库里有两个脚本，各自负责一个页面。区分的办法很简单：商品排行榜页的地址以 `/product` 结尾，商品详情页的地址是 `/product/detail?id=xxxx`，官网在 detail 后面接上商品 ID。

## 商品排行榜页的脚本能做什么

该脚本用来快速展示排行榜上商品的中文名，并把商品信息快速导出为 Excel。脚本面板带页面跟随功能，滚动网页时面板第一条商品会对齐到网页第一条商品，左右一眼就能对照，不用两边都滚动。

**注意**：商品导出的数据是网页上显示的数据，导出数据的颗粒度与网页自带的导出数据不一致。页面上显示的数据，对于上万的数字，只能精确到百位，脚本中导出数据的做法是将网页的 12.34 万改成 123400；如果需要更精确的数据，请使用网页自带的导出功能。

在此之上还加了几件顺手的事：输入关键词就能快速高亮命中的商品；储存后，点击词条可以直接勾选符合关键词的商品，再通过导出功能一次性导出。该脚本也做了一些网页优化，减少等待时间和内存占用。如果一次调研分几批导出了零散的表格，还可以用 XLSX 合并功能把这些表格快速拼成一份 xlsx。

## 商品详情页的脚本能做什么

该脚本主要解决快速寻找与高频信息收纳：对于常用的内容提供一键定位，点击一下即可快速跳转；对于常用的高频信息提供一键复制，对于规格信息一键复制纯数字；页面里被收纳起来的「更多」也会自动点开，省得逐个展开。

商品信息会被整理成便于复制的形式，卖点、属性、规格、净含量这类数据点一下就能复制；像规格、净含量这种只要数字的场景，可以在设置页里配好关键词，让该脚本自动筛出数字。对于重要的商品信息，也可在设置页面设置优先展示。该脚本同样对网页进行了部分优化，能够屏蔽拖慢页面加载的第三方广告与埋点请求，极大地节约网页的加载时间。

最后一点是留给维护的：该脚本把定位用的锚点和 CSS 选择器集中成一份配置，页面发生微小变化后，可以实现快速修改，也可以把配置以 JSON 和 AI 提示词一并导出，交给 AI 帮忙调整，再粘回来生效。这样网页微调时不必翻代码，也能较快地把失效的功能修回来。

## 适用环境、网站和页面

两个脚本都是普通的用户脚本，用脚本猫、Tampermonkey、Violentmonkey 都能装，建议用 Chromium 系浏览器，并且需要先登录 Kalodata 账号并购买相关 VIP 功能。两个脚本都不需要任何额外授权，把对应的 `.user.js` 文件拖进扩展的安装页面即可。

排行榜脚本只在 `https://www.kalodata.com/product` 生效，详情页脚本只在 `https://www.kalodata.com/product/detail?id=...` 生效，其他页面不会启动。面板宽度、左右位置、各项开关和关键词都会记在浏览器本地，调整后会保存，下次打开还在。

## 大致是怎么实现的

### 排行榜脚本

该脚本在页面开始渲染之前就先运行，先记下浏览器原生的窗口宽度读数，再改写该读数。站点读到的是修改后的宽度，于是网页本体按收窄后的宽度排版，空出来的一侧留给脚本自己绘制的面板。面板用 Shadow DOM 和站点的样式隔开，互不干扰，滚动时再跟表格逐行对齐。

商品数据直接来自页面里已经加载好的表格，中文名借页面自身的翻译能力补齐，结果缓存在本地。高亮、勾选这些状态只在脚本内部计算，最后把选中的行在浏览器里直接打包成 Excel 下载，不需要任何外部库。

### 详情页脚本

分区布局的思路和上面一样，不同之处在于该脚本把「怎么找到页面上的某个元素」单独收成一张定位表，选择器、路径、接口地址都写在这里，其他代码不重复写死。设置页既能逐项改，也能把整份配置和一段提示词复制出来交给 AI；页面结构小改之后，把 AI 返回的 JSON 粘回去就能恢复，跳转时补一点固定偏移是为了定位到更加需要的位置，能够极大地减少鼠标的滚动。

自动展开、点击即复制、规格数字筛选，以及拦掉那些把页面拖慢的第三方广告埋点，都是搭在这套结构上的小功能。因为定位知识集中在一处，改起来比翻遍整个文件要省事得多。
